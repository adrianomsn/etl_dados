Este repositório tem como objetivo construir um projeto de ETL completo end-to-end

O fluxo atual pensado se dará nestas etapas:
1. Extração de dados: Coleta de dados de fontes externas, como bancos de dados ou APIs.
2. Transformação: Processamento dos dados coletados, normalização, limpeza, etc.
3. Lógica de negócio: Aplicações de negócio, como validações, validações de dados, etc.
4. Armazenamento: Armazenamento dos dados processados, como bancos de dados ou arquivos.

O projeto tem como objetivo criar um fluxo de trabalho completo de ETL, incluindo a extração, transformação, lógica de negócio e armazenamento.

Nesse contexto iremos utilizar as seguintes ferramentas:
1. Scripts em Python para consumo de APIs, transformação e carregamento de dados.
2. Big Query para armazenamento dos dados.
3. Airflow para gerenciamento de fluxos de trabalho.
4. Git para controle de versões.
5. Github para hospedagem do repositório.

Resumidamente, caso seja necessário pode ser que façamos alguma troca de stack, mas o plano inicial é este.
